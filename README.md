# AutoHotkey Pipeline Compiler

A repository for managing and automatically compiling AutoHotkey scripts using GitHub Actions.

## Overview

This repository provides an automated pipeline for compiling AutoHotkey scripts into standalone executables.

## Scripts

### space-nav.ahk

A space-based navigation script that enables Vim-style navigation:

- **Hold Space + h/j/k/l**: Use as arrow keys (h=Left, j=Down, k=Up, l=Right)
- **Tap Space alone**: Types a space character
- **Regular h/j/k/l**: Work normally when space is not held
